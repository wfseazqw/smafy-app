# 上码FY · 二维码生成与活码工作台

由 小帆帆 搭建的轻量版「草料二维码」：生成静态二维码 + 活码（图案不变、内容可随时改）+ 批量生码。
纯 Node.js，无需数据库，数据存于本机 `data/codes.json`。

## 启动
```bash
cd shangma-fy
npm install      # 首次需要
npm start        # 或 node server.js
```
打开 http://localhost:3000

## 功能
- **生成静态码**：文本 / 网址 / 名片 / WiFi / 电话 / 短信 / 邮件
- **美化**：前景色、背景色、容错率、尺寸、边距、中心 Logo；下载 PNG / SVG，一键复制
- **活码工作台**：保存后可随时改内容，二维码图案不变；带扫描次数统计；扫码页自动适配手机
- **批量生码**：每行一个，`标签|内容` 格式，一键出图

## 部署（让别人也能扫）
- 本机运行：同一 WiFi 下用电脑内网 IP 访问（如 http://192.168.x.x:3000）
- 上线：部署到任意支持 Node 的平台（Railway / Render / 腾讯云 CloudBase / Netlify 等），
  设置启动命令 `npm start`、端口环境变量 `PORT` 即可。活码链接会自动使用线上域名。

## 说明
- 活码本质：二维码图案编码一个短链接 `/c/xxxx`，内容存在服务器，修改内容时图案不变。
- 本地运行时活码短链指向 localhost，手机需在同一网络用电脑 IP 才能扫开；部署后即为公网域名。

## 现在怎么用（已配好临时公网）
已通过 localtunnel 把本机网站暴露到公网，手机/别人现在就能扫：
- 公网地址：见运行 `npx localtunnel --port 3000` 后输出的 `https://xxxx.loca.lt`
  - 首次打开会有一个 **“Continue”确认页**（每台设备每 7 天一次），点一下即可进入网站。
- 本机打开：http://localhost:3000
- 手机同 WiFi（最干净、无确认页）：http://192.168.1.22:3000

⚠️ 临时公网地址在**重启电脑 / 重连网络后会变化**（localtunnel 随机分配）。
想要一个**固定不变**的公网地址，需要部署到云平台（见上方「部署」），用一个免费账号即可，部署后活码链接永久有效。

## 重启后一键启动
双击 `启动.bat` 即可同时拉起网站与公网隧道。
